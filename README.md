# Экзамен завтра

2D-игра о студенте, который проводит ночь в общежитии перед экзаменом в 9:00.

**Версия:** MVP v1.0
**Команда:** AuRus

## Правила
- Ночь идёт с 21:00 до 09:00 (12 реальных минут).
- К 09:00 нужно набрать не менее 70 знаний.
- Учитесь по учебнику, спите, пейте кофе (3 порции).
- Сосед шумит пять раз за ночь, и тогда учёба идёт хуже.
- Если бодрость падает до нуля, персонаж засыпает на 30 минут.

## Управление
Мышь: нажимайте на предметы комнаты и выбирайте действие.

## Технологии
Godot 4.7 (.NET), язык C#.

## Как запустить
1. Установите Godot 4.7 (версия .NET) и .NET 8 SDK.
2. Откройте Godot, нажмите Import и выберите файл project.godot.
3. Нажмите Alt+B (сборка), затем F5 (запуск).

## Структура проекта
- scenes/ — сцены (меню, игра, настройки)
- scripts/ — код на C#
- assets/ — картинки и звуки
